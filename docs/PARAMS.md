## 大舵机（M1/M2/M3 = 40 x 40 x 20）结构核实（2026-10-22）

学长口径"40x40x20"不是 40x40 的方饼，而是 **宽40 x 厚20 x 高40**。三处互证：

1. **Hiwonder 官方规格 51.1 × 20.14 × 40 mm**（hiwonder.com / hiwonder.hk / robotshop / openelab 四处一致），
   其中 51.1 = 本体 40 + 两侧接线座 11.1。**学长确认：51.1 不算，只算本体 40x40x20。**
2. **官方实物图**：舵盘（主输出轴）从**顶面**伸出，底面另有一个辅助轴（虚轴）——
   所以"双轴"就是顶面 + 底面两个轴端，同轴贯穿整个本体。
3. **学长原话"大舵机有四个 40x20 的面"**：40(宽) x 40(高) x 20(厚) 的箱体，
   正好 2 个 40x40 面（法向厚度）+ 4 个 40x20 面。完全吻合。

推论（已落库）：

    输出轴沿"高 40"方向 → 轴端在两个 40x20 面上 → 轴垂直于 40x20 面
    ⇒ 轴端面 = 40x20 面；轴上沿"长40"方向偏心，只沿"厚20"方向居中
    ⇒ 关节原点 = 输出轴，盒中心 = 原点 + (20 - 10) = 10mm，朝"远离 0 边"一侧

对应各关节的盒偏移（引擎反查，改前 → 改后）：

    M2_should  ORIENT(40,40,20)  长40=x  盒偏 (0,0,0) → (+10, 0, 0)   轴沿 y
    M3_elbow   ORIENT(20,40,40)  长40=z  盒偏 (0,0,0) → ( 0, 0,+10)   轴沿 y

## 输出轴位置（绝对坐标，不是"偏心"）

学长用面局部坐标系定义，直接落库：

    45x25 面局部坐标：x 沿 45 方向 [0,45]，y 沿 25 方向 [0,25]
    四点 (0,0) (0,25) (45,25) (45,0)
    输出轴在 (10, 12.5)
    0 边朝上一级（M3 侧）

落到实现：舵机盒中心在面局部坐标是 (22.5, 12.5)，所以
    盒中心 - 输出轴 = (22.5-10, 12.5-12.5) = (+12.5, 0)
即舵机盒相对关节原点偏 +12.5mm（沿 45 维），沿 25 维为零。
